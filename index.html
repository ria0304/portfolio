Operations Research · Water-Resource Optimization
AquaRoute — Reliable Community Water Distribution
Models reservoirs, communities and pipelines as a single-commodity network-flow LP and decides how much water each route carries, with minimum-service guarantees for priority communities and transshipment through neighbouring communities. A two-stage lexicographic solve maximises service first, then applies the strategy objective, so five allocation strategies differ only in how they spread unavoidable shortages. A linearised proportional-fairness metric keeps the model an LP, and a solver-free analytical fallback takes over when no solver is installed or the LP is infeasible. An evaluation suite benchmarks four baselines against demand spikes, supply cuts and pipeline failures with seeded, reproducible CSV/JSON exports, significance tests and a Streamlit dashboard. 60 tests, GitHub Actions CI on Python 3.10–3.12.
Network-Flow LP Python Pyomo · HiGHS NetworkX Streamlit · Plotly GitHub Actions

Causal ML · Fairness in Deepfake Detection
FairFaceGuard — Deepfake Detection Under Skin-Tone and Lighting Variations
Research pipeline that asks whether a deepfake detector's accuracy gap across skin-tone groups is really about skin tone, or about illumination cues that merely correlate with it. Faces get illuminant-corrected ITA/Fitzpatrick labels, then matched counterfactuals (skin-only, light-only, both) with an automated manipulation check. A frozen EfficientNet-B4 baseline is interrogated three ways — adversarial GRL sweeps, linear probing, and a counterfactual causal test — with bootstrap CIs and a paired permutation test. Currently a single-seed pilot on a FaceForensics++ Deepfakes-only subset; multi-seed, cross-dataset (Celeb-DF) and backbone-ablation runs are written but not yet run.
Causal Counterfactuals Python PyTorch EfficientNet-B4 · FaceForensics++ GRL Disentanglement Bootstrap CI · Permutation Test

Multimodal AI · Hallucination Mitigation
VisualGuard — Evidence-Guided Decoding for LVLMs
Training-free, decoding-time method that cuts object hallucination in Large Vision-Language Models without touching the weights. At every step it scores each top-k candidate token by how well the image supports it, using LVLM attention, CLIP similarity and optional Grounding DINO region detections, then penalises the logits of unsupported candidates before the next token is chosen. Includes a KV-cached decoding loop, a per-step intervention audit trail, POPE and MME evaluation on LLaVA-1.5, ablation runners, and 297 tests that need no downloads.
LVLM · Hallucination Reduction Python PyTorch Transformers CLIP · Grounding DINO LLaVA-1.5 POPE · MME
